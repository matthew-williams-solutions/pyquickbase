# Security policy

Please don't report vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/matthew-williams-solutions/pyquickbase/security/advisories/new)
instead, and include steps to reproduce the problem.

Only the latest release is supported. This is a volunteer project, so response times may vary.

If a Quickbase token may have been exposed, revoke it in Quickbase right away.
